# How to play

No compiling needed: download the ready-to-run Windows build.

## What you need
- Windows 10 or 11.
- **Your own** disc image of *Yu-Gi-Oh! Forbidden Memories* (USA, **SLUS-01411**): the `.bin` file of a `.bin/.cue` pair. Pick the `.bin`, not the `.cue`. No game data is included.
- Nothing to install: no emulator and no compiling.

## Steps
1. Download [`JourneyMode_v0.6.0-alpha_Windows.zip`](https://github.com/omagodev/forbidden-memories-journey-mode/releases/download/v0.6.0-alpha/JourneyMode_v0.6.0-alpha_Windows.zip) (or the newest one in [Releases](https://github.com/omagodev/forbidden-memories-journey-mode/releases/latest)).
2. Extract the **whole** zip into a folder (don't run it from inside the zip).
3. Copy your `.bin` into the `game` folder, or pick it with **Choose ROM...** on the first launch.
4. Double-click **`JOGAR_JourneyMode.bat`** (recommended, it turns on HD text) or `memories-pc.exe`.
5. If SmartScreen warns you: **More info → Run anyway** (the program isn't signed; the source is right here).
6. On the title screen choose **NEW GAME**, create your character and go. **CONTINUE** loads your save.

## Keyboard
| Key | Action |
|---|---|
| Arrows | Move / navigate |
| X or Enter | Confirm / talk |
| S | Back / cancel (Circle) |
| A | Journal / map (Triangle) |
| Z | Square (shop tabs / extras) |
| Q / W | L1 / R1 |
| E / R | L2 / R2 |
| Enter | Start (pause menu) |
| Right Shift | Select (minimap) |
| F10 | Menu bar (video, controls, language) |
| Esc | Quit |

## Controller (Xbox / PlayStation / Switch-style)
Plug in a USB or Bluetooth gamepad — SDL maps it automatically. Stick and D-pad both move.

| Button | Action |
|---|---|
| Left stick / D-pad | Move / navigate |
| A / South (✕) | Confirm / talk |
| B / East (○) | Back / run (hold on the map) |
| Y / North (△) | Journal (illustrated map) / world map |
| X / West (□) | Square actions (shop / UI) |
| Start | Pause menu |
| Select / View / − | Minimap |
| LB / RB | L1 / R1 |
| LT / RT | L2 / R2 |

## Remap keys and buttons
1. In Journey Mode open **Start → Controls** (opens the PC Controls window), **or** press **F10 → Game → Controls…**.
2. Click a row and press the key or button you want. Conflicts are moved automatically.
3. **Apply** or **OK** — bindings save to `controls.txt` in your user folder (`Documents\My Games\YFM Re-Decomp`).

Keyboard and gamepad share the same actions, so Journey Mode, shops, wagers and duels all follow your remap.

## Star Chips (Duelist Kingdom)
- Before every star duel you **choose your bet**: left/right from 1 up to the smaller of your stars and your rival's, X to duel, S to back out.
- Win and you take the bet from him. Lose and he **keeps** it; challenge him again to win it back.
- **If your stars run out, it is GAME OVER**: you go back to the title and CONTINUE loads your last save (the game never saves at zero stars). Never bet your last star lightly.
- The gates count only the stars in your hand; ten open the castle.

Saves go to `Documents\My Games\YFM Re-Decomp`. Found a bug? [Open an issue](https://github.com/omagodev/forbidden-memories-journey-mode/issues) and attach `game.log` from the game folder.
