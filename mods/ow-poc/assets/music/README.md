# Journey Mode soundtrack

Original looping themes for Journey Mode exploration, tension and finale cues.

They replace the port's BGM ids through the mod `audio.music` table in `mod.json` (Ogg Vorbis). The themes were synthesized for this mod; they are not Konami / Forbidden Memories disc music.

|---|---|---|

| `village_night.ogg` | Village (night) | 25 |
| `cistern.ogg` | Cistern | 26 |
| `harbor.ogg` | Harbor | 18 |
| `ship.ogg` | Ship deck | 20 |
| `beach.ogg` | Kingdom beach | 30 |
| `forest.ogg` | Forest | 21 |
| `mountain.ogg` | Mountain | 22 |
| `meadow.ogg` | Meadow | 19 |
| `desert.ogg` | Desert | 23 |

| `castle_hall.ogg` | Castle Hall | 52 |
| `castle_dream.ogg` | Dream Room | 27 |
| `tension_wager.ogg` | Star wager UI | 54 |
| `epic_heishin.ogg` | Heishin confrontation | 55 |
| `epic_pegasus.ogg` | Pegasus finale | 56 |

Cue hooks: wager picker → tension; `dk9_heishin_pre` → epic_heishin; `dk10_pegasus_pre` → epic_pegasus; wish/epilogue → epic_festival.
