# Trilha sonora do Modo Jornada

Temas originais em loop para exploração, tensão e o final do Reino.

Eles substituem os ids de BGM do port pela tabela `audio.music` do `mod.json` (Ogg Vorbis). Os temas foram sintetizados para este mod; não são a música do disco da Konami / Forbidden Memories.

| Arquivo | Clima | Track id |
|---|---|---|
| `village_day.ogg` | Vila (dia) | 10 |
| `village_night.ogg` | Vila (noite) | 25 |
| `cistern.ogg` | Cisterna | 26 |
| `harbor.ogg` | Porto | 18 |
| `ship.ogg` | Navio | 20 |
| `beach.ogg` | Praia do Reino | 30 |
| `forest.ogg` | Floresta | 21 |
| `mountain.ogg` | Montanha | 22 |
| `meadow.ogg` | Campina | 19 |
| `desert.ogg` | Deserto | 23 |
| `fair.ogg` | Feira das Estrelas | 24 |
| `castle_gate.ogg` | Portão do Castelo | 51 |
| `castle_hall.ogg` | Salão do Castelo | 52 |
| `castle_dream.ogg` | Sala dos Sonhos | 27 |
| `tension_wager.ogg` | Aposta de estrelas | 54 |
| `epic_heishin.ogg` | Confronto com Heishin | 55 |
| `epic_pegasus.ogg` | Final com Pegasus | 56 |
| `epic_festival.ogg` | Epílogo do Festival | 57 |

Cues: seletor de aposta → tensão; `dk9_heishin_pre` → epic_heishin; `dk10_pegasus_pre` → epic_pegasus; desejo/epílogo → epic_festival.
