# Roadmap

Journey Mode is a hobby project, so there are no dates here, just the direction. Each item will become a GitHub issue; feel free to pick one up.

## ✅ Done
- Painted home town (Oasis Village), cistern and underground arena, with animated water, fire and palms
- NPCs on the map linked to Forbidden Memories duelists; real duels with the original engine
- Dialogue with the speaker's name in the text box, a yes/no ask, objective and item banners
- Quests, journal, objective arrow and mini-map
- Character creator with layered sprites (body, outfit, hair, accessory)
- Duelist Kingdom chapter 1 (home town to the ship), in English and Portuguese
- LPC walking sprites for the main cast
- Small key-hint icons instead of big action bars; a dev mode toggle in the START menu options
- Fast test scenarios (jump to any story point)

## 🚧 In progress
- **Economy:** money, a shop in every town, card drops only from the local pool
- **Duelist gang:** ambushes at a set frequency, no escape, a loss costs money
- **Clandestine arenas:** farm local cards, gain XP and levels
- Balancing difficulty across the economy, the gang and the arenas

## 🔜 Next
- Painted harbor and ship deck; the rest of chapter 1 on real maps
- Duelist Kingdom chapters 2-10: star wagers, island zones, the castle and Pegasus
- Mago.dev's observer appearances and the ending
- More towns, each with its own shop, card pool and arena
- Accented Portuguese text

## 🌐 Big ideas
- **Online multiplayer:** meet friends on the map and duel them
- Trading cards between players
- A map and quest editor for the community
- A 3D or PS1-hardware build again, if the vertex budget ever allows it
